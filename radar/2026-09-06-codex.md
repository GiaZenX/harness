## Findings

### 1. Codex CLI 0.153.1–0.153.4 (2026-09-03/04): `gpt-6-astra` is now the CLI's own bundled default model when none is configured — checked, no exposure in this repo's generator
- **Source**: https://learn.chatgpt.com/docs/changelog (seen 2026-09-06) — 0.153.4 (2026-09-04):
  *"Made Astra visible in the bundled model picker and set it as the default when no model is
  explicitly configured"*; 0.153.1 (2026-09-03): API-only Astra config without changing the picker
  default; 0.153.2 (2026-09-03): a display-text-only fix to an "Astra Fast" price-tier label ("2x
  speed, increased usage" instead of "1.5x"); 0.153.3 (2026-09-04): Astra added to the Bedrock model
  picker. Cross-checked https://developers.openai.com/api/docs/models/gpt-6-astra (seen 2026-09-06):
  **no separate "Astra Fast" model id exists** — "Fast mode" is a 2x-price processing-speed modifier
  on the single `gpt-6-astra` id, not a new rung candidate.
- **What it is**: these four patch releases landed the day after (0.153.1-3) and the day of (0.153.4)
  yesterday's report's cutoff, so they were not yet visible then. The material one is 0.153.4: Codex
  CLI itself, not just the vendor's model catalog, now defaults an unconfigured session to
  `gpt-6-astra`.
- **Why it matters to this harness**: this could have been a real exposure — a kit whose generated
  `.codex/agents/*.toml` ever omitted `model` would silently start running that role on whatever the
  CLI defaults to, which just changed out from under it. **Checked directly**:
  `team-kits/gen_provider_artifacts.py` lines 883-891 (`gen_codex_agent`) always resolve and emit an
  explicit `model = "..."` line for every role — falling back to `"sonnet"` (translated) only when a
  kit source names no pin at all, never leaving the field absent for the CLI to fill in. Same pattern
  at lines 810-819 for the top-level `.codex/config.toml` default. So the CLI default-model change is
  a **no-op for every kit this repo ships** — noted as a confirmed check, not a gap.
- **Recommendation**: **no action**. Worth one line in `PR-0010`'s protocol (AC-5, "what a project
  sees if its pinned model no longer exists") only if that AC's write-up ever discusses *unpinned*
  roles — it doesn't need to, since none exist. **Status**: NEW (confirmation, not a candidate)
